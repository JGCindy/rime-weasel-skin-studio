字体写了却没变？按这个顺序查（按命中率排序）：
① 名称必须和系统里一字不差：Microsoft YaHei UI 和 Microsoft YaHei 是两个字体。 正确做法是在系统「字体设置」里看字体的字体名称，不是文件名。工具会自动填入回退链，把同一个字体登记的几个名字全列上 （例 汉仪夏日体W, HYXiaRiTiW；载入过字体文件的还会带上它的西文族名与 PostScript 名，例 方正FW轻吟体 简 B, FZFW Qing Yin Ti Jian B），小狼毫从左往右依次尝试、先命中者生效——不用自己纠结写中文名还是英文名， 关键是别写错，链上也不会串到别的字体去。
①′ 版本前提：逗号回退链是 weasel 0.15.0 起才支持的。更老的版本会把整串当成一个字体名，反而导致字体完全不生效—— 托盘图标右键能看到版本号，太老就升级，或把 font_face 改成单个名字。
② 文件位置：必须放 %APPDATA%\Rime\weasel.custom.yaml（托盘图标右键 →「用户文件夹」），不能放在程序安装目录。
③ 别覆盖已有文件：如果那个文件已经存在（小狼毫自己生成过，里面有 customization: 和 app_options:），不要整个覆盖，只把 patch: 段合并进去。一个文件里只能有一个 patch: 段且必须顶格。
④ 编码与格式：保存为 UTF-8 无 BOM；缩进只能用空格、不能用 Tab；冒号后面必须有一个空格。
⑤ 必须重新部署：托盘图标右键 →「重新部署」。还不生效就先「结束算法服务」，删掉 %APPDATA%\Rime\build 文件夹，再重新部署。
⑥ 看日志：用户文件夹里的 weasel.log，搜 error / warning 能看到具体哪行配置出错。
另外：字体本身要先装进系统（选中字体文件 → 右键 →「为所有用户安装」），皮肤只能调用系统里已装的字体。
网页部署后字体不显示：浏览器不允许网页读你本机的字体文件。点「⤓ 导出含字体的网页」生成内嵌字体的单文件 HTML，部署那一份就行。
